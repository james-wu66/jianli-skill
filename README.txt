========================================
  简历定制器 · 使用说明
========================================

【这是什么】
一个跑在你自己电脑上的简历定制工具：
上传你现有的简历 → 自动建立个人档案 → 贴上目标岗位的 JD（职位描述）→
大模型把你的项目经历按岗位重排改写（绝不编造你没有的经历）→
生成一份和你原简历版式一模一样的 Word，并给你一个诚实的匹配分。

你的所有数据只存在你自己的电脑上，不会上传到任何服务器。

----------------------------------------
【第一次使用（约 10 分钟）】
----------------------------------------

第 1 步：安装 Python（电脑里没有才需要）
  1. 打开 https://www.python.org/downloads/
  2. 下载 Python 3.10 以上版本，双击安装
  3. ⚠ 安装时务必勾选底部的 "Add python.exe to PATH"

第 2 步：启动
  双击文件夹里的 启动.bat
  → 会弹出一个黑色窗口（这就是服务，用的时候保持开着，关掉 = 停止）
  → 浏览器会自动打开 http://127.0.0.1:5050

第 3 步：填写模型 key（必填，一次性）
  点页面右上角「设置」：
  - API Key：去商汤 https://platform.sensenova.cn 注册，
    在控制台创建 API key，粘贴进来（新用户有免费额度）
  - BASE_URL：https://token.sensenova.cn/v1
  - 模型名：sensenova-6.8-flash-lite
  点「测试连通」——它测的就是你刚填进去的这组值（不用先保存），
  看到「主模型 ✅ 连通正常」再点「保存」。
  备用那行显示 ⚠ 未配置 是正常的：备用模型选填，不填也能用。
  key 只存在你自己电脑的 profiles/api_key.json 里。

第 4 步：建立个人档案
  第一次打开页面会自动进入向导：
  上传你现有的简历（.docx）→ 自动解析 → 核对修改 → 保存。
  之后随时可以点右上角「我的资料」修改。

第 5 步：生成简历
  左边贴目标岗位的 JD（岗位职责+任职要求整段复制）
  → 点「生成定制简历」→ 等几十秒 → 下载 Word。

----------------------------------------
【进阶：skill 版（不起服务、不用 key）】
----------------------------------------

同一个内核还有第二个入口：不经过网页，直接交给支持 skill 的 AI Agent（Qoder / Claude 等）驱动。
判断由宿主模型做，脚本只做确定性活儿（校验下标、原地换字、读写档案）。

  优点：不花你的 API 额度、不用起服务、整条流程不到一秒
  代价：简历内容会进入你和 Agent 的对话上下文（走模型厂商服务器），介意就别用这条

装法：把 skilldizi 这个文件夹整个放进你的 Agent 的 skill 目录
      （Qoder 是 C:\Users\你的用户名\.qoder\skills\）。
用法：对 Agent 说"照 skilldizi\SKILL.md 帮我按这份 JD 改简历"，它自己去跑那四个命令行入口。

⚠ 两个入口的档案目录是分开的：网页版用根目录的 profiles\，
   skill 版用 skilldizi\profiles\，互不同步。同一份档案想两边都用得自己复制。

----------------------------------------
【注意事项（都是实测踩过的坑）】
----------------------------------------

1. 不要双击 index.html 打开页面！那样连不上服务。
   一定通过 启动.bat 启动，浏览器地址栏是 http://127.0.0.1:5050

2. 生成有时 10 秒、有时 1~3 分钟，都是正常波动。
   等的时候可以刷新页面，不会中断；等太久页面会出现"重新生成"按钮。

3. 页面上的红色报错如果一直挂着，重新点一次生成即可（旧报错不会自动消失）。

4. 服务已经开着的时候，再双击一次 启动.bat 没关系，它会直接打开页面。

5. 匹配分是诚实打分：分数低说明这个岗位跟你不匹配，参考着筛岗位用。

6. 想修改简历内容：右上角「我的资料」。
   想换 key：右上角「设置」。

7. 这个工具保持版式的方式是"在你自己那份 docx 上原地换文字"，不是重画。
   所以：不解析 PDF、不改配色、不重排版式、不自动填网申表。简历必须是 .docx。

8. 版式识别目前只在两份真实简历上验证过（内置示例 + 作者自己的一份）。
   换一份别人设计的简历时，一定要逐项核对它报出来的识别结果——
   没识别到的区域会原样保留你的模板内容，如果那份模板参考过别人的简历，残留的就是别人的信息。

9. 不要拿"在 Word 里改过几行又另存"的简历配旧模板直接生成。Word 存盘会重新切分文字节点，
   位置一漂内容就写到别的行上去了。现在程序会直接拦住并报数字，遇到就重新识别一次版式。

10. 简历上能放几条要点/几条技能，是你的模板决定的，不是程序写死的。
    模板技能区只有 3 行就只放得下 3 条；想多放先在 Word 里把行数加出来。

----------------------------------------
【常见问题】
----------------------------------------

Q: 双击 启动.bat 提示找不到 Python？
A: Python 没装好或没勾 "Add python.exe to PATH"，重新安装一次并勾选。

Q: 解析我的简历失败？
A: 确认是 .docx 格式（WPS/Office 另存为 docx）。.txt/.md 也可以但无法
   用它当版式模板。

Q: 生成的 Word 里求职意向/项目还是我原文没变？
A: 说明版式识别时该区域没映射上，页面上解析时会有黄色提示。可以把简历
   另存为标准 docx 再重新上传一次。

Q: 我的 key 能给别人共用吗？
A: 不要。key 等于你的付费账户，谁用谁出额度。
