# 简历定制器（resume-tailor）

**上传你的简历 → 贴上目标岗位 JD → 一键生成"内容定制 + 版式不变"的 Word 简历，附诚实的岗位匹配分。**

本地运行，简历数据不出你的电脑；大模型只做"重排 + 改写"，没有编造经历的权限。

---

## 它解决什么问题

秋招海投几十个岗位，每个岗位都想要一份"侧重点不一样"的简历。手动改？每份 30 分钟起步，
还容易改漏。这个工具做的事情：

1. **建档一次**：上传你现有的简历，大模型自动解析成结构化档案（可人工核对修改）
2. **贴 JD 生成**：分析岗位方向 → 重排项目模块顺序 → 关键词对齐 JD → 技术栈按方向筛选
3. **版式原样保留**：⭐ 核心特性——生成的 Word 用的是**你自己上传的简历版式**，
   版式、形状、配色一模一样，只换文字内容
4. **诚实打分**：逐条对比 JD 要求（匹配/部分匹配/缺失），给出真实的匹配分和投递建议，
   分数低就是真的低，不灌迷魂汤

**红线**：不编造任何你没有的技能/实习/经历（写死在引擎里的全局硬规则）。

## 核心技术亮点

| # | 亮点 | 说明 |
|---|---|---|
| 1 | **LLM 自动模板映射** | dump 上传 docx 的全部文字节点，让大模型输出"节点→内容区域"映射配置，经下标越界/一址多写/槽数一致性校验后，实现任意简历模板的原地文字替换（VML/DrawingML 双套内容都处理） |
| 2 | 长任务异步化 | 生成要 10 秒~3 分钟，采用"后台线程任务池 + 前端 2 秒轮询 + sessionStorage 断点续查"，刷新页面不中断生成 |
| 3 | LLM 输出容错 | 强制 JSON 输出 + 截断恢复算法（补括号重试）+ 字段补全兜底 + 主备双模型自动切换 |
| 4 | 推理模型提速 | 关闭 reasoning 思考过程，实测快 3.6 倍（48s → 13s） |
| 5 | 提示词分层 | 全局硬规则（防编造，不可关）+ 个人规则（表述红线/标签黑白名单，档案配置） |

## 快速开始

```bash
# 1. 安装依赖（需要 Python 3.10+）
pip install -r requirements.txt

# 2. 启动
python app.py
# Windows 用户直接双击 启动.bat

# 3. 浏览器打开
# http://127.0.0.1:5050
```

启动后：

1. 点右上角「**设置**」填入你的大模型 API key
   （推荐商汤 [sensenova](https://platform.sensenova.cn)，新用户有免费额度；
   任何 OpenAI 兼容接口都可以）
2. 首次使用会自动进入向导：上传你的简历（.docx）→ 核对解析出的档案 → 保存
3. 贴 JD → 生成 → 下载 Word

## 目录结构

```
├── app.py              # Flask 接口层：路由 + 后台任务池
├── generate.py         # 生成引擎：提示词 + JD 分析 + 匹配打分
├── wizard.py           # 首次向导：简历解析 + 模板映射（两个核心提示词）
├── template_export.py  # 模板引擎：docx 节点原地替换
├── resume_parser.py    # 简历文件解析（支持文本框型 docx）
├── profile_store.py    # 个人档案读写（profiles/*.json）
├── llm_client.py       # 模型调用：主备双供应商 + 容错
├── index.html          # 前端单页应用（原生 JS，无框架）
├── assets/templates/   # 内置模板包（含示例档案生成的演示模板）
└── profiles/           # 个人档案（示例-张三.json 可参考结构）
```

## 配置

| 配置项 | 位置 | 说明 |
|---|---|---|
| API key | 网页「设置」页 → `profiles/api_key.json` | 推荐方式，每台电脑自己的 |
| API key（文件） | `llm_config.py`（参考 `llm_config.example.py`） | 文件方式，适合命令行党 |
| 个人档案 | `profiles/<名字>.json` | 网页「我的资料」页可视化编辑 |
| 个人规则 | 档案里的 `rules` 字段 | 表述红线 / 技能标签黑白名单 |

## 常见问题

**Q: 生成的 Word 版式和我上传的简历一样吗？**
一样。工具把你上传的 docx 当模板，只替换文字节点，形状/图片/版式原样保留。
个别区域识别不到时会在解析完成时明确提示（该区域保持你原文不动）。

**Q: 会不会编造我没有的经历？**
不会。"禁止新增档案里没有的技能/项目/实习"是写死在引擎里的全局硬规则，任何用户不可关闭。

**Q: 匹配分准吗？**
打分纪律要求"宁可诚实偏低"：JD 里明确要求而你确实没有的，会被判"缺失"并如实扣分。
分数反映真实拿到面试的概率，不是简历好不好看。

**Q: 我的数据会上传吗？**
生成时简历内容会发送给你自己配置的大模型服务商（这是调用的必要代价），
但不会上传到本工具的任何服务器——它就是跑在你电脑上的本地服务。
